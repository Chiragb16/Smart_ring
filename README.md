Smart Ring
A compact, wearable IoT device designed to monitor vital health parameters such as heart rate, body temperature, and motion activity. The Smart Ring integrates multiple sensors into a power-efficient design, making it ideal for continuous health tracking and wellness analysis.

Features
Real-time heart rate and SpO₂ measurement using MAX30102
Body temperature monitoring with MAX30207 sensor
Motion and activity tracking via BMI270 or MPU6050 accelerometer
Low-power operation using ESP32-C3 Supermini microcontroller
Bluetooth Low Energy (BLE) communication for data transfer
Compact PCB design optimized for wearable enclosures
Rechargeable or coin-cell battery-powered design (CR2032 support)

Power Management
Auto-sleep functionality for low power usage
Optimized for operation with CR2032 battery (~3V)
Deep-sleep current < 10 µA (typical)

Applications
Continuous health monitoring
Sleep quality tracking
Physical activity detection
Wellness and fitness analytics

Future Improvements
Integration with smartphone app dashboard
Wireless charging module
Advanced AI-based anomaly detection
Multi-sensor calibration and data fusion
